# AyuMitra AI: Frontend

React + TypeScript + Vite + Tailwind CSS (shadcn/ui conventions), Framer Motion, React Query and Axios.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to Django on :8000
npm run build
npm run lint
```

Brand tokens live in `src/index.css`. See the root [README](../README.md) for the full project.
